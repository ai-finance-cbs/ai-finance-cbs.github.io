# B8403 site: aesthetic rules (draft v20261007)

Base: Gallery Minimal ("one white wall"). Content supplies the hierarchy; controls stay quiet.

## 1. Surfaces
- Pure white background. No shadows, no gradients, no left accent bars.
- Structure comes from 1px #ECECEC hairlines. A panel is a hairline box with 6px corners.

## 2. Type (two families, fixed roles)
- Reading text (paragraphs, lists, table cells): Source Serif 4, 17px (tables 15.5px).
- Interface (nav, labels, buttons, badges, status lines): Helvetica Neue, 12-15px.
- Page title: serif, 34px. Section label inside a panel: Helvetica, 13px, uppercase, letter-spacing 0.14em.
- No italics for emphasis. Use weight.

## 3. Colour
- Ink #1A1A1A; body #444; muted #6B6B6B; hairline #ECECEC.
- One action colour: blue #2F6FB8, for links, buttons, and the active state.
- Red #8C2F39 only for staff-only controls (Tools) and warnings.
- Extra colours only where they encode data (task-map labels, status pills).

## 4. Buttons: three kinds only
| Kind | Look | Use for |
|---|---|---|
| Primary | Filled blue, white text | The one main action in a form: Save, Submit |
| Secondary | White, 1px grey border | Cancel, Export to PDF, Add |
| Text action | Blue text, no box | Small actions on content: Edit, Delete, Open in CourseWorks → |

At most one primary button per form. Editing controls never look heavier than the content they edit.

## 5. Layout
- Reading pages (Syllabus, Library, assignments, examples): one 740px column at the same left edge.
- Staff grids (gradebook, attendance, roster): wide layout, compact 13px type, Canvas-style.
- Spacing in steps of 4px; 14-20px between panels.
